# Ghostline Chess

Ghostline Chess is a C# Windows Forms chess game developed by Ghostline Interactive Studios.

This project began as an object-oriented programming side project and became my first playable game built in C#.

## Current Features

- Complete 8×8 chessboard
- White and black chess pieces
- Turn-based gameplay
- Piece selection and highlighting
- Standard movement rules for all pieces
- Capturing
- Blocked-path detection
- Check detection
- Prevention of moves that expose the king
- Checkmate detection
- Stalemate detection
- New Game button

## Technologies

- C#
- .NET
- Windows Forms
- Object-oriented programming
- Git and GitHub

## Project Structure

- `Enums` — piece colors, piece types, and game results
- `Models` — chess pieces and board squares
- `GameLogic` — board setup, movement validation, turns, and game results
- `FrmMain` — Windows Forms user interface

## Planned Features

- Castling
- Pawn promotion
- En passant
- Move history
- Improved board graphics
- Sound effects
- Additional game settings

## Running the Project

1. Clone or download the repository.
2. Open `GhostlineChess.slnx` in Visual Studio.
3. Build the solution.
4. Press `F5` to run the game.

## Development Status

Ghostline Chess is a playable prototype and is still under development.
